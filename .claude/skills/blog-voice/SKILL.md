# blog-voice — 文体の適用手順

## 手順

1. **`site/<domain>/voice.md` を読む** — 文体スペックの正本。ここに書いてある表だけが判定基準。
2. **`site/<domain>/post-index.json` から既存記事を3本選び、raw content を読む**
   - 選び方: 対象カテゴリと同じ記事を優先。最近公開されたものを優先。
   - 読む目的: 導入の書き出し・段落の短さ・コードへのコメントの入れ方・定型句の使い方を肌で合わせる。
   - スキップ禁止。「voice.md を読んだ」だけでは書き始めない。
3. **voice.md の「書く前の思考矯正6手順」を通してから書く**
4. 書いた後、**禁止カテゴリ2表（AI典型構文・英語直訳調）を1行ずつ機械的に検索**して消す
5. `blog-quality-gate` の文体 lint に通ることを確認

## 絶対禁止

- voice.md を読まずに記憶で書く
- 既存記事を読まずに書く
- 「〜することができます」「これにより」「〜と言えるでしょう」等の NG 表を残す
- 一人称（私・自分・当サイト）を使う
- 命令形単体・常体・関西弁を本文に混ぜる

## レジスタの境界

- 適用対象: `site/<domain>/` の記事本文（段落・capbox・FAQ・まとめ）
- 適用しない: コメント返信下書き・PR/Issue・チャット応答（別レジスタの skill がある）
